intentree

Helps people follow what LLM coding agents build. Agents record a project's design intent as sentences in controlled English: strict enough for a deterministic parser, plain enough to read as notes. intentree compares the sentences with what it can find in the code and draws them as several views, so it is easier to see what was built and where it drifted from what was meant.

How it works

  1. Write sentencesThe agent states the design in controlled English, one sentence per line, in a .intent file beside the code.
  2. Check against the codeA deterministic parser reads them and compares them with the files, symbols and imports it finds. Gaps and drift are listed, not guessed.
  3. See the viewsThe same sentences are drawn as structure, deployment, concurrency, state machines and constraints. In each demo, the real tool runs beside the simulator.
